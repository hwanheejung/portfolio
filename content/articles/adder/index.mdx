계산기는 복잡해 보이지만, 가장 작은 단위에서는 0과 1을 다루는 스위치의 조합입니다.
이 글에서는 논리 게이트를 연결하면서 덧셈이 만들어지는 과정을 살펴봅니다.

## 반가산기

가능한 모든 경우를 진리표로 나타내면 다음과 같습니다.

<TruthTable
  labels={[
    { label: "A", type: "input" },
    { label: "B", type: "input" },
    { label: "Sum", type: "output" },
    { label: "Carry", type: "output" }
  ]}
  data={[
    { A: 0, B: 0, Sum: 0, Carry: 0 },
    { A: 0, B: 1, Sum: 1, Carry: 0 },
    { A: 1, B: 0, Sum: 1, Carry: 0 },
    { A: 1, B: 1, Sum: 0, Carry: 1 }
  ]}
/>

논리 게이트로 구현하면 아래와 같습니다.

<Circuit
  id="half-adder"
  initialJSON={{
    nodes: [
      { id: "a", label: "A" },
      { id: "b", label: "B" },
      { id: "sum", label: "SUM" }
    ],
    edges: [
      { from: "a", to: "sum" },
      { from: "b", to: "sum" }
    ]
  }}
/>

<Callout title="직접 바꿔보세요">
  회로의 스위치를 켜고 끄면서 진리표와 같은 결과가 나오는지 확인할 수 있습니다.
</Callout>
